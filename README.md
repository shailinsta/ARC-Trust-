# README

# ARC-Trust+: Asynchronous Riemannian Coordination for Trust-Aware Decentralised Federated Intrusion Detection under Drift and Byzantine Attack

## Overview

ARC-Trust+ is a research-driven, fully decentralised (serverless) framework for federated intrusion detection in telecommunication and industrial IoT networks. It combines asynchronous contribution control, temporal geometry on symmetric positive-definite (SPD) covariance matrices, and a multi-signal trust model, so that agents can resist malicious model updates under non-IID data, concept drift, and message delay/loss without any central monitor.

Each honest agent runs the same four-step cycle, followed by a trust-weighted aggregation and one Karcher update of its local SPD reference:

1. **TAEC**: Topology-Aware Exclusive Cache with bounded staleness
2. **RTDR**: Riemannian Temporal Deformation Residual (affine-invariant parallel transport)
3. **CCI**: Canary Consistency Indicator (cryptographic integrity bit)
4. **CTE**: Composite Trust Evaluation (EMA smoothing, two-strike local isolation)

## Key Features

- Fully Decentralised Federated Intrusion Detection (no central orchestrator)
- Asynchronous Contribution Control:
  - One valid update per neighbour per cycle
  - Updates older than S_max = 5 rounds are discarded
  - Aggregation only after the participation threshold (60% of neighbours) is met
- Temporal Riemannian Geometry:
  - Regularised SPD covariance state per agent
  - Affine-invariant parallel transport, log/exp maps and Karcher mean
  - Rank-8 tangent representation
- Multi-Signal Trust Model:
  - Temporal geometric residual
  - Canary integrity bit
  - Freshness (age decay)
  - Historical trust (EMA smoothing)
- Byzantine Robustness:
  - Sign-flip, Gaussian-noise and ALIE attacks
  - 0%, 10%, 20%, 30% and 40% Byzantine participation
- Drift-Aware Evaluation:
  - None | Abrupt | Gradual | Recurring | Stealth drift (drift starts at round 18)
- Baseline Comparison: FedAvg, coordinate-wise Median, Multi-Krum, Sync, distance-only, canary-only
- Ablation Study: No residual | No canary | No staleness | No EMA
- Reproducible Colab pipeline (5 datasets × 3 seeds, resumable)

## Datasets

Five public intrusion-detection datasets are used. They are **not** redistributed in this repository; the notebook downloads them automatically on first run.

| Dataset | Source |
|---|---|
| UNSW-NB15 | GitHub (official train/test split) |
| NF-ToN-IoT-v2 | Kaggle: `dhoogla/nftoniotv2` |
| NF-CSE-CIC-IDS2018-v2 | Kaggle: `dhoogla/nfcsecicids2018v2` |
| CIDDS-001 | Kaggle: `dhoogla/cidds001` |
| Edge-IIoTset | Kaggle: `mohamedamineferrag/edgeiiotset-cyber-security-dataset-of-iot-iiot` |

Data protocol (leakage-free):

- Train/test split is made **before** feature selection (UNSW-NB15 uses its official split; the others use a stratified 70/30 split)
- The top 25 mutual-information features and the scaler are fitted on training rows only
- Host and session identifiers (IPs, ports, timestamps, payload text) are dropped
- Non-IID partition across 10 agents (Dirichlet α = 0.5)

## Pipeline Workflow

1. Dataset download and loading
2. Feature sanitisation (missing/infinite values, constant features)
3. Leakage-free train/test split and mutual-information feature selection
4. Feature scaling (training split only)
5. Non-IID partition across 10 agents (Dirichlet α = 0.5)
6. Controlled concept-drift injection (from round 18)
7. Asynchronous network simulation (ring + Erdős–Rényi graph, 10% message loss, bounded delay)
8. Byzantine attack injection (sign-flip / Gaussian / ALIE, canary token attached)
9. Local training (logistic regression, 4 SGD steps per round, learning rate 0.08)
10. TAEC admission, RTDR residual, CCI integrity bit, CTE trust update
11. Two-strike local isolation of low-trust neighbours
12. Trust-weighted aggregation and Karcher reference update
13. Baseline comparison (FedAvg, Median, Multi-Krum, Sync, distance-only, canary-only)
14. Ablation, Byzantine-fraction and drift-regime experiments
15. Tables and figures export

## Trust Model

Instantaneous trust of neighbour *j* (weights α = 1.0, β = 3.0, γ = 0.5):

```
T_j = (α·φ_j + β·C_j + γ·exp(−S_j)) / (α + β + γ)
τ_j ← λ·τ_j + (1 − λ)·T_j,   λ = 0.7
```

A neighbour is isolated, permanently and locally, if τ_j < τ_iso = 0.35 for two consecutive admitted updates.

| Component | Description |
|---|---|
| φ_j (Residual) | Median-normalised Riemannian temporal deformation residual, in (0, 1] |
| C_j (Canary) | 0 if the canary token is present in the payload, otherwise 1 |
| exp(−S_j) (Freshness) | Decay with the age S_j of the admitted message |
| τ_j (Historical trust) | Exponential moving average of past trust scores |

## Evaluation Metrics

- **Macro-F1**: measured on honest agents over a hold-out window
- **Isolation recall**: fraction of Byzantine neighbours isolated
- **False-isolation rate**: fraction of honest neighbours wrongly isolated
- **Mean trust**: honest vs Byzantine neighbours
- Balanced accuracy, attack-F1, recall and false-positive rate for honest agents
- Robustness across attack types, Byzantine fractions and drift regimes

## Experimental Results

Primary setting: 20% Byzantine participation, sign-flip attack, stealth drift. Macro-F1, mean ± std over 3 seeds.

| Dataset | ARC-Trust+ | FedAvg | Median | Multi-Krum | Sync |
|---|---|---|---|---|---|
| CSE-CIC-IDS2018 | **0.827 ± 0.037** | 0.809 ± 0.024 | 0.795 ± 0.015 | 0.817 ± 0.021 | 0.805 ± 0.024 |
| CIDDS | **0.811 ± 0.022** | 0.777 ± 0.032 | 0.774 ± 0.019 | 0.796 ± 0.043 | 0.778 ± 0.038 |
| Edge-IIoTset | 0.852 ± 0.009 | 0.780 ± 0.036 | 0.746 ± 0.069 | 0.792 ± 0.060 | 0.779 ± 0.036 |
| ToN-IoT | **0.757 ± 0.024** | 0.712 ± 0.025 | 0.684 ± 0.070 | 0.711 ± 0.062 | 0.704 ± 0.021 |
| UNSW-NB15 | 0.665 ± 0.045 | **0.672 ± 0.016** | 0.662 ± 0.031 | 0.658 ± 0.036 | **0.672 ± 0.012** |

ARC-Trust+ has the highest mean Macro-F1 among the methods above on four of five datasets (on Edge-IIoTset the canary-only variant is marginally higher, 0.854 vs 0.852). On UNSW-NB15, FedAvg and Sync are slightly higher.

### Isolation and Trust

Across all five datasets and all three attack types (sign-flip, Gaussian noise, ALIE): isolation recall = **1.000**, false-isolation rate = **0.000**. Mean honest-neighbour trust is about 0.88–0.91 and mean Byzantine-neighbour trust is about 0.22–0.31, below τ_iso = 0.35.

### Ablation (sign-flip, 20% Byzantine, stealth drift)

| Variant | Isolation recall | False-isolation rate |
|---|---|---|
| Full ARC-Trust+ | 1.000 | 0.000 |
| No residual | 1.000 | 0.000 |
| No canary | 0.000 | 0.000 |
| No staleness | 1.000 | 0.000 |
| No EMA | 1.000 | 0.000 |

### Robustness to Byzantine Fraction (ARC-Trust+, Macro-F1)

| Dataset | 0% | 10% | 20% | 30% | 40% |
|---|---|---|---|---|---|
| CSE-CIC-IDS2018 | 0.833 | 0.827 | 0.827 | 0.823 | 0.817 |
| CIDDS | 0.804 | 0.800 | 0.811 | 0.796 | 0.812 |
| Edge-IIoTset | 0.841 | 0.853 | 0.852 | 0.848 | 0.829 |
| ToN-IoT | 0.759 | 0.758 | 0.757 | 0.755 | 0.752 |
| UNSW-NB15 | 0.662 | 0.666 | 0.665 | 0.664 | 0.688 |

Under sign-flip attacks, ARC-Trust+ stays within about 0.03 of its zero-Byzantine Macro-F1 up to 30% Byzantine participation on the datasets above, while FedAvg degrades on four of five datasets (e.g. Edge-IIoTset: 0.839 → 0.739 at 30%).

## Key Insights

- ARC-Trust+ outperforms FedAvg on four of five datasets under sign-flip attacks with stealth drift
- Macro-F1 is stable across 30% Byzantine participation and across all five drift regimes
- Results depend on traffic distribution and attack type (UNSW-NB15 is the exception; under Gaussian noise the canary-only variant is highest on four datasets)
- Isolation is driven by the cryptographic canary; the residual contributes to trust weighting

## Research Contributions

- Asynchronous contribution control protocol (topology-aware exclusive cache with bounded staleness)
- Temporal geometry-based behavioural assessment (SPD deformation residual via affine-invariant parallel transport)
- Multi-signal trust fusion with integrity verification (residual + freshness + canary)
- Heterogeneous evaluation on five real intrusion-detection datasets with three attack types and five drift regimes

## Important Notes

- **Canary caveat:** in the evaluated threat model, Byzantine agents carry the canary token and honest agents do not, so the canary acts as an oracle. Isolation results are conditional on this design. The independent ability of SPD geometry to identify Byzantine neighbours is **not** established (see the *No canary* ablation).
- Only 3 random seeds are used; no significance tests are reported, so claims apply to means and standard deviations only.
- Fixed 10-agent topology, simple logistic-regression local classifier and scheduled (synthetic) drift.
- Communication and computation costs were not measured.
- Datasets are third-party; follow their original licences and terms.
